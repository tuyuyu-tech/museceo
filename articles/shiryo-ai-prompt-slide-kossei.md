## はじめに

社内資料・企画書のたたき台作りに毎回1時間以上かかっている人向けに、無料のChatGPT・Claude・Geminiにそのまま貼って使えるプロンプト3本をまとめました。登録不要、初期費用0円です。

結論：資料は「AIに骨子を作らせる→人間が数字と固有名詞を直す」の順にすると3分でたたき台ができます。コツは、構成を **「背景→課題→提案→費用対効果→次の一手」の5枚** に固定することです。

職種別の3問診断＋コピペボタン付き版はこちら（登録不要・データ収集なし）。

## 1. 骨子5枚のたたき台（基本の型）

テーマと読者を書くだけで、社内説明用の5枚構成が出ます。初期費用0円の縛りを入れると現実的な案が出ます。

```
あなたは企画アシスタントです。以下のテーマで社内説明用スライドの骨子を作ってください。
条件：タイトル案3つ／構成は「背景→課題→提案→費用対効果→次の一手」の5枚／各スライド3箇条書き／専門用語はかみ砕く。

【テーマ】：（例：請求書処理のAI時短案）
【読者】：（例：非ITの上司）
【制限】：（例：初期費用0円・無料ツールのみ）
```

ChatGPT（無料）でもClaude（無料）でも動きます。迷ったらChatGPTでまず1案出し、言い回しを整えたい部分だけClaudeに投げると速いです。

## 2. 反対意見の先回り（通る資料の裏技）

提案が通らない原因の9割は「上司のツッコミへの備え不足」です。出す前に反対意見を3つ予想させて返答を用意します。

```
以下の提案への反対意見を3つ予想し、各々への返答を2行で用意してください。上司目線で、数字の根拠が弱い点は「要確認」と明記すること。

【提案】：
（ここに1.で作った骨子の提案部分を貼る）
```

「コストは？」「前例は？」「失敗したら？」の3点に答えられると、そのまま1枚足すだけで承認率が上がります。

## 3. 費用対効果の1枚要約（決裁者向け）

決裁者が見るのはこの1枚だけです。「現状コスト→提案→削減見込み→初期費用0円の根拠」の4行に圧縮します。

```
以下を「現状コスト→提案→削減見込み→初期費用0円の根拠」の4行で要約してください。数字は仮置きと明記し、誇大な表現は使わないこと。

【内容】：
（ここに提案内容を貼る）
```

数字は仮置きで構いません。「月○時間→○時間」「担当1名×○分」など、自分の実感値で置き換えてから出すのがコツです。

## 運用フロー（3分の内訳）

1. テーマ・読者・制限の3行だけ書く（1分）
2. プロンプト1→2→3の順に貼って出力させる（1分）
3. 人間が確認：数字・固有名詞・期限を直す（1分）

3の確認は削れません。AIは数字や実績をそれっぽく盛ることがあるため、金額・期間・担当だけは必ず目視してください。

## 注意（必ず読んでください）

- 顧客名・金額・人事情報などの機密は貼らないでください。無料プランは入力が学習に使われる可能性があります。固有名詞は「A社」「担当B」のように仮名化するのが安全です。
- 社内ルールで生成AIの利用制限がある場合は、必ずルールに従ってください。
