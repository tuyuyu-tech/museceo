## はじめに

会議後の議事録作成に30分以上かかっている人向けに、無料のChatGPT・Claude・Geminiにそのまま貼って使えるプロンプト3本をまとめました。登録不要、初期費用0円です。

結論：議事録は「録る→AIに構造化させる→人間が確認する」の3手順にすると10分で終わります。コツは、AIへの指示に **「決定／TODO（担当・期限）／未決」の3箱** を指定することです。

職種別の3問診断＋コピペボタン付き版はこちら（登録不要・データ収集なし）。

## 1. 雑メモ→決定事項＋TODO化（基本の型）

箇条書きの殴り書きメモを貼るだけで、決定事項とTODOに分けてくれます。曖昧な部分は「要確認」と書かせるのがポイントです。

```
あなたは議事録の整理担当です。以下のメモを「決定事項／TODO（担当・期限）／未決事項」に分けて要約してください。
条件：各5行以内／曖昧な表現は「要確認」と明記／固有名詞は変えない。

【メモ】：
（ここに箇条書きメモを貼る）
```

Claude（無料）は長文の整形が自然なので、議事録用途の第一候補です。迷ったらChatGPT（無料）でも問題ありません。

## 2. 1時間会議→5行要約＋共有文

長い会議の後は、要約→共有文→TODO表の順で出させます。関係者への共有まで一気に終わります。

```
以下を5行要約→関係者共有文100字→TODO表（担当・期限）で出力してください。

【メモ】：
（ここに箇条書きメモを貼る）
```

## 3. 音声起こし文の整形

ボイスレコーダーの起こし文は冗長語だらけなので、まず整形だけさせます。要約は別に3行で出させると混ざりません。

```
以下の起こし文を、冗長語削除・敬体統一・段落分けして整形してください。意味は変えないこと。要約は別に3行で付けること。

【起こし文】：
（ここに貼る）
```

## 運用フロー（10分の内訳）

1. 会議中は箇条書きメモだけ取る（0分・会議と同時進行）
2. プロンプト1〜3に貼って出力させる（3分）
3. 人間が確認：数字・固有名詞・担当・期限をチェック（5分）
4. 共有文をチャットに貼って終わり（2分）

3の確認は削れません。AIは日時や数字を hallucinating することがあるため、担当・期限・金額だけは必ず目視してください。

## 注意（必ず読んでください）

- 顧客名・金額・人事情報などの機密は貼らないでください。無料プランは入力が学習に使われる可能性があります。固有名詞は「A社」「担当B」のように仮名化するのが安全です。
- 社内ルールで生成AIの利用制限がある場合は、必ずルールに従ってください。
