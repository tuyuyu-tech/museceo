## はじめに

事務・営業・人事・就活生など、「文章に時間がかかる」人向けに、無料のChatGPT・Claude・Geminiにそのまま貼って使えるプロンプト術をまとめました。登録不要、初期費用0円です。

結論から言うと、コツは1つだけです。**「要件を箇条書きにして、AIに整形させる」**。この順番にするだけで、メール・議事録・資料のたたき台が3分でできます。

## 1. 丁寧メール返信（断り＋代替案）

メモを貼って整形させるのがコツです。断る場合は代替案を1つ添えると角が立ちません。

```
あなたは丁寧なビジネス文の編集者です。以下のメモを、相手に失礼のないメール文に整えてください。
条件：件名案1つ／本文200〜300字／敬語／断る場合は代替案を1つ添える／最後に確認事項を箇条書き。

【メモ】：
（ここに要件を箇条書きで貼る）

【相手】：（例：取引先・上司・応募先）
【自分の立場】：（例：事務担当）
```

## 2. 議事録→決定事項＋TODO化

「決定／TODO（担当・期限）／未決」に分けさせます。曖昧な部分は「要確認」と書かせるのがポイントです。

```
あなたは議事録の整理担当です。以下のメモを「決定事項／TODO（担当・期限）／未決事項」に分けて要約してください。
条件：各5行以内／曖昧な表現は「要確認」と明記／固有名詞は変えない。

【メモ】：
（ここに箇条書きメモを貼る）
```

## 3. 資料の骨子（3分たたき台）

「背景→課題→提案→費用対効果→次の一手」の5枚でたたき台を作らせます。初期費用0円の縛りを入れると現実的な案が出ます。

```
あなたは企画アシスタントです。以下のテーマで社内説明用スライドの骨子を作ってください。
条件：タイトル案3つ／構成は「背景→課題→提案→費用対効果→次の一手」の5枚／各スライド3箇条書き／専門用語はかみ砕く。

【テーマ】：（例：請求書処理のAI時短案）
【読者】：（例：非ITの上司）
【制限】：（例：初期費用0円・無料ツールのみ）
```

## 注意（必ず読んでください）

- 数字・固有名詞・敬語は必ず人間が確認してください。重要文書は二重チェックです。
- 個人情報・顧客データ・社外秘は貼らないでください。無料プランは入力が学習に使われる可能性があります。固有名詞は仮名に置き換えるのが安全です。
